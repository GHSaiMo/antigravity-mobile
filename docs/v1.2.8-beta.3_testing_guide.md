# Multigravity `v1.2.8-beta.3` 公测版升级与测试指南

> **适用版本**：Gateway `v1.2.8-beta.3` · iOS TestFlight `1.2.8 (52)` · Android `v1.2.8-beta.3`（`versionCode 44`）· Web / PWA（随网关内置）  
> **Release 页面**：https://github.com/GHSaiMo/antigravity-mobile/releases/tag/v1.2.8-beta.3

`v1.2.8-beta.3` 属于 **Pre-release 灰度测试版**，常规的 `mgy update`、一键安装脚本与 Android 应用内自动更新均默认只检测最新正式版（`v1.2.7`）。按照本指南即可手动切换至 `beta.3` 体验全量新特性，测试结束后随时可无损切回正式版，**已配对主机、配置与本地缓存均会完整保留**。

> 💡 **强烈建议双端同步升级**：电脑端 `mgy` 网关与手机端客户端均升级至 `beta.3` 后，才能完整体验智能辅助套件、远程宿主机更新、防气泡消失修复与新版定时任务等全栈能力。

## 第一步：升级电脑 / 服务器网关（`mgy`）

### 情况 A：已安装过 `mgy`（macOS / Linux / Windows 通用）

在终端中指定版本号一键升级（内置 SHA-256 校验与镜像自动回退）：

```bash
mgy update -version v1.2.8-beta.3
```

> ⚠️ **此前已安装过早期 `beta.3` 的用户**：本次 `v1.2.8-beta.3` 已覆盖更新至最新构建，请务必加上 `-force` 强制重新拉取覆盖：
> ```bash
> mgy update -version v1.2.8-beta.3 -force
> ```

### 情况 B：尚未安装 `mgy` 的新用户

先运行一键安装脚本完成初始化，再切换到 `beta.3`：

- **macOS / Linux / Windows (Git Bash)**：
  ```bash
  # 国内推荐（加速镜像）
  curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/GHSaiMo/antigravity-mobile/main/scripts/install.sh | bash
  mgy update -version v1.2.8-beta.3
  ```
- **Windows (PowerShell)**：
  ```powershell
  # 国内推荐（加速镜像）
  irm https://ghfast.top/https://raw.githubusercontent.com/GHSaiMo/antigravity-mobile/main/scripts/install.ps1 | iex
  mgy update -version v1.2.8-beta.3
  ```
- *海外或终端已开启代理用户，可去掉命令中的 `https://ghfast.top/` 前缀直接从 GitHub 拉取。*

### 情况 C：手动下载覆盖（终端网络受限时兜底）

前往 [v1.2.8-beta.3 Release 页面](https://github.com/GHSaiMo/antigravity-mobile/releases/tag/v1.2.8-beta.3) 下载对应架构压缩包，解压后替换 `~/.local/bin/mgy`（Windows 为 `%USERPROFILE%\.local\bin\mgy.exe`）：

| 系统 / 架构 | 对应压缩包 |
| :--- | :--- |
| macOS Apple Silicon (M 系列) | `multigravity-darwin-arm64.tar.gz` |
| macOS Intel (x86_64) | `multigravity-darwin-amd64.tar.gz` |
| macOS 通用包 | `multigravity-darwin-universal.tar.gz` |
| Linux x86_64 | `multigravity-linux-amd64.tar.gz` |
| Linux ARM64 | `multigravity-linux-arm64.tar.gz` |
| Windows x86_64 | `multigravity-windows-amd64.zip` |

### 重启网关并确认版本

升级完成后，**必须重启正在运行的网关进程**，新版本才会生效：

- **后台服务模式（`mgy service`）**：
  ```bash
  mgy service restart
  ```
- **前台终端 / tmux 会话模式**：先按 `Ctrl + C` 停止旧进程，再重新执行：
  ```bash
  mgy
  ```
- **验证生效**：执行 `mgy version`，或查看启动横幅确认显示为 **`v1.2.8-beta.3`**。

## 第二步：升级手机端与 Web 端

### 1. iOS（TestFlight `1.2.8 (52)`）

1. 未安装 TestFlight 或尚未加入公测通道的用户，先打开公开邀请链接加入：  
   👉 https://testflight.apple.com/join/YM7f4aSK
2. 打开手机上的 **TestFlight** App，找到 **Multigravity**，点击更新至 **`1.2.8 (52)`**。
3. TestFlight 版本可直接覆盖 App Store 正式版，已配对的网关、模型偏好与历史缓存不会丢失。

### 2. Android（`Multigravity-v1.2.8-beta.3.apk`，`versionCode 44`）

1. 下载最新 `beta.3` 安装包：
   - **GitHub 原链**：https://github.com/GHSaiMo/antigravity-mobile/releases/download/v1.2.8-beta.3/Multigravity-v1.2.8-beta.3.apk
   - **国内加速直链**：https://ghfast.top/https://github.com/GHSaiMo/antigravity-mobile/releases/download/v1.2.8-beta.3/Multigravity-v1.2.8-beta.3.apk
2. 安装说明：
   - 当前为 **`v1.2.7` 或 `v1.2.8-beta.1/2/3`** 的用户：同独立私有正式签名（SHA-256: `79:D8:15:B5:...35:5C:A9`），**直接覆盖安装**即可。
   - 当前为 **`v1.2.6` 及更早版本**的用户：因 `v1.2.7` 起切换了独立私有签名，本次需**先卸载旧版再安装一次**，打开后扫码 3 秒即可恢复配对；之后即可永久直接覆盖升级。

### 3. Web / PWA 端

- Web 控制台与 PWA 页面已直接内置于 `mgy` 网关二进制中，无需单独下载。
- 电脑端 `mgy` 升级并重启后，刷新网页（或关闭 PWA 后重新打开一次）即可加载最新界面与 Service Worker（`v88`）。

## 第三步：重点新功能与回归测试清单

建议按以下顺序逐项体验，重点关注边界场景与手感反馈：

### 1. 智能辅助套件（AI Assist）
入口：**设置 → 智能辅助**（开关跨设备同步至网关，底层调用本机 Antigravity 无状态接口，不产生多余会话）

- **智能翻译**：
  - 开启「会话标题翻译」后新建英文提问会话，确认标题生成后自动译为简体中文并覆盖；
  - 开启「步骤清单实时翻译」与「实时状态行翻译」，在复杂任务执行期间核对步骤卡片、状态行与 iOS 灵动岛/锁屏实时活动的中文译文效果。
- **下一步提示词建议胶囊（重点体验）**：
  - 开启「下一步提示词建议」，待 Agent 回复完成后查看输入栏 `+` 右侧出现的建议胶囊：
  - **排版**：确认建议文案优先沿首行完整向右延伸（可自然挤出模型胶囊），占满整行宽度后再折为多行完整展示；
  - **短按**：轻点胶囊，确认文字准确填入输入框方便修改；
  - **长按 1.5 秒直发**：按住胶囊约 0.18 秒后底部与背景进度条开始线性推进，**走满 1.5 秒**自动震动并直接发送；**中途提前松手**进度条平滑回退并取消发送（不会误填入输入框）；
  - **自动隐藏与关闭**：点击胶囊右上角 `×` 可关闭；存在审批卡片、`Proceed/Continue` 按钮或输入框已有草稿时自动隐藏；
  - **手势说明**：前往 **设置 → 使用技巧与快捷手势**，确认「短按模型胶囊」下方已补充「提示词建议胶囊」的短按与长按 1.5 秒说明。
- **长会话防失忆（压缩后自动回灌上下文）**：
  - 开启后检查本机 `~/.gemini/config/hooks.json` 是否自动写入轻量 `PreInvocation` Hook，在长对话执行 `/compact` 或自动压缩后的下一轮观察上下文衔接效果。

### 2. 发送气泡稳定性回归（重点验证）
- 分别使用**手动输入发送**与**长按建议胶囊 1.5 秒直发**发送多轮消息（建议也测试连续发送相同短语，如「继续」「好的」）：
  - 确认蓝色用户气泡发出后**稳定常驻，不再短暂消失 1~2 秒后重现**；
  - 确认聊天顶栏轮次计数（如 `第 2/2 轮`）同步及时，不闪回上一轮，底部不误现回底 `v` 按钮；
  - 对刚发送的消息执行一次**撤回（Undo）**，确认撤回预览与回滚均正常放行、不卡死。

### 3. 远程网关一键自更新 & 宿主机更新二级页
入口：**设置 → 关于 → 宿主机更新**
- 验证「宿主机更新」已切换为独立二级页面（iOS 支持原生推入与右滑返回，Android / Web 支持平滑横滑与跟手右滑返回）；
- 核对页面内 Antigravity 桌面端与 `mgy` 网关的版本状态展示是否准确。

### 4. 配额监控、阈值自动切号与上下文拆解
- **阈值自动切号**：在配额页面展开「阈值自动切号」，测试为 Gemini / Claude 的 5h 或 Weekly 额度池设置阈值，确认默认勾选「等待当前任务空闲后切换」不打断运行中对话；
- **上下文占比拆解**：在对话顶部点击上下文圆环，查看上下文拆解视图（Context Breakdown）与动态成本/配额预估，确认 iOS 半屏高度自适应无裁切；
- **模型与额度池对齐**：检查双列模型选择器、`XHigh` 命名与边框展示，以及使用 Claude 驱动 Orchestrator 时正确归属 Claude 额度池。

### 5. 定时任务（Automations）、多斜杠指令与 HTML 预览
- 测试通过 **Prompt 创建定时任务**，打开定时任务会话确认首条触发提示词默认折叠且支持点按展开；
- 在输入框连续选择并组合**多个 `/command` 斜杠指令**发送，确认按选择顺序正确执行；
- 让 Agent 生成一个面向用户的 `.html` 文件，确认消息流自动以**可交互 HTML 预览卡片**展示并保留正确扩展名。

### 6. 网关后台服务与累积 Beta 特性（按需体验）
- **跨平台开机自启**：
  ```bash
  mgy service install    # 注册并启动后台服务（Windows 需管理员 PowerShell）
  mgy service status     # 查看服务与端口探活状态
  mgy service logs -f    # 实时查看轮转日志
  mgy service uninstall  # 不再需要时一键停用卸载
  ```
- 其他 `v1.2.8-beta.1` / `beta.2` 累积能力：Antigravity 2.35.2 浏览器实时预览（Live View）与触控接管、远程 SSH 主机管理、插件市场检索与 OAuth 闭环、一机多主机自由切换、`/btw` 旁路内收抽屉与树形连线、局域网 `mgy hub` 聚合。

## 第四步：常见问题排查与反馈建议

### 常见问题

1. **运行 `mgy update -version v1.2.8-beta.3` 提示「当前已是最新版本」？**  
   说明本机已装过同版本号的旧版 `beta.3`，加上 `-force` 强制覆盖下载即可：
   ```bash
   mgy update -version v1.2.8-beta.3 -force
   ```

2. **终端更新完成了，但手机端连上还是旧功能或旧 Web 界面？**  
   多半是旧的 `mgy` 进程尚未重启。执行 `mgy service restart`（后台服务）或在运行终端中 `Ctrl + C` 后重跑 `mgy`；Web / PWA 端强制刷新或重启一次 App。

3. **iOS 在 TestFlight 中还没刷出 `1.2.8 (52)`？**  
   刚上传的 Build 需要苹果后台处理几分钟，可在 TestFlight 中下拉刷新重试。

4. **Android 覆盖安装提示「安装包与现有应用签名冲突」？**  
   这是因为当前安装的是 `v1.2.6` 或更早版本的旧签名包。先卸载旧版再安装 `Multigravity-v1.2.8-beta.3.apk` 即可，之后所有版本均支持直接覆盖升级。

### 问题反馈请尽量附带以下信息
- **设备与版本**：iOS / Android / Web、客户端版本号（如 `iOS 1.2.8 (52)`）、网关版本（`mgy version` 输出）及电脑系统（macOS / Linux / Windows）；
- **复现步骤**：最好附带简短录屏或截图；
- **网关日志**：如遇连接、发送或流式异常，可提供对应时间段的终端输出或 `mgy service logs` 片段（注意自行抹去隐私信息）。

## 第五步：无损回退至正式版（`v1.2.7`）

测试完成后，如需切回当前稳定正式版（`v1.2.7`）：

- **电脑端网关**：
  ```bash
  mgy update -version v1.2.7
  ```
  *(升级后同样记得重启网关：`mgy service restart` 或重启前台 `mgy`)*
- **iOS**：打开 [App Store](https://apps.apple.com/app/id6835508934) 点击「安装 / 获取」即可覆盖切回正式版，配对数据保留。
- **Android**：在 App 内前往 **设置 → 关于 → 版本** 检查更新，或前往 [Latest Release](https://github.com/GHSaiMo/antigravity-mobile/releases/latest) 下载 `Multigravity-v1.2.7.apk` 直接覆盖安装。
